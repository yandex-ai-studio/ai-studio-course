# Установка окружения Python на свой компьютер

Самый простой способ установить Python нужной версии со всеми необходимыми библиотеками на компьютер - это использовать пакетный менеджер [uv](https://docs.astral.sh/uv/).

Мы предполагаем, что вы уже клонировали репозиторий курса себе на компьютер командой
```bash
git clone https://github.com/yandex-ai-studio/ai-studio/course
```
или скачали архив с файлами из репозитория и распаковали в директорию на своём компьютере.

Чтобы установить среду для работы с ноутбуками курса на свой компьютер или виртуальную машину выполните следующие шаги из командной строки:

1. Установите пакетный менеджер uv [по этой инструкции](https://docs.astral.sh/uv/getting-started/installation). После установки вам должна стать доступна команда `uv`.

2. Запустите сервер Jupyter Lab со всеми необходимыми зависимостями одной командой, находясь в корневой директории репозитория курса:
```bash
uv run --with jupyter --with-requirements requirements.txt jupyter lab
```
Если вы выполняете эту команду на настольном компьютере - откроется браузер, в котором вы сможете работать со средой Jupyter Lab.

3. Теперь вы можете открывать любые ноутбуки курса и запускать их. Поскольку вы уже установили все необходимые библиотеки перед запуском Jupyter Lab, начальные ячейки с командами `%pip install` вы можете пропускать.

## Точные версии библиотек

В репозитории курса файл `requirements.txt` содержит названия необходимых библиотек, без указания точных версий. Мы рассчитываем, что пакетный менеджер сам подберет последние совместимые версии библиотек, чтобы вы использовали самые современные версии.

Однако со временем библиотеки могут изменяться, из-за чего фрагменты кода могут переставать работать. Если вы хотите использовать те же версии библиотек, которые использовались при создании курса, и на которых работа ноутбуков была проверена - используйте имя файла `requirements-strict.txt` вместо `requirements.txt`.

## Установка на виртуальную машину

Вы также можете запустить сервер Jupyter Lab на виртуальной машине в облаке Yandex Cloud, и затем обращаться к ней из любого браузера через интернет. В этом случае последовательность шагов такая же, как в инструкции выше - но в команде запуска Juptyter Lab необходимо указать флаг `--ip=0.0.0.0`:
```bash
uv run --with jupyter --with-requirements requirements.txt jupyter lab --ip=0.0.0.0
```

## Установка переменных окружения

Вы также можете заранее установить переменные окружения для работы с Yandex Cloud перед запуском Jupyter Lab - это позволит в дальнейшем пропускать ячейки с загрузкой файла `.env`. Перед запуском Jupyter Lab выполните команды:
```bash
export folder_id=...
export api_key=...
```
или, для Windows:
```cmd
set folder_id=...
set api_key=...
```

Если ключи находятся в файле `.env`, вы можете указать файл `.env` прямо при запуске Jupyter Lab:
```bash
uv run --with jupyter --with-requirements requirements.txt --env-file=.env jupyter lab --ip=0.0.0.0
```
